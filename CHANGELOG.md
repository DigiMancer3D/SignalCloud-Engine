# Changelog

## v0.1.0-alpha.1 — 2026-08-01

First public source alpha.

### Release engineering

- added deterministic public-source staging and archive generation;
- excluded generated builds, reports, saves, machine profiles, caches, archives,
  prompt histories, and private development state;
- added readable local-path normalization and high-confidence credential blocking;
- added MIT licensing with CC0 preservation for declared starter assets;
- added standalone XDG dependency/environment paths for public extraction;
- added public install, release, contribution, security, and GitHub publication guidance;
- curated phase-report history from the public package and moved the active tactical
  map prototype out of the legacy source directory;
- added deterministic ZIP release output, release manifests, and a one-command
  GitHub CLI publication helper.

### Accepted engine/game foundation

- Pivot 13 game runtime and 8M/4M adaptive environment profile;
- engine-native stress campaigns, workload registry, machine profiles, watchdog,
  recovery, thermal authority, memory policy, and persistent truthful final HUD;
- SignalCloud Studio, Point Cloud Paint++, +SCFS+, Illuminosity, Material/Jitter,
  Playbook, Showcase, and Tupd tools;
- SCFONT, SCUI, protected authoring reload, authored light/material/audio runtimes,
  threat director, traversal, combat, recovery, economy, kiosks, AR, and tactical memory.

### Known limitations

- Linux-first source release; no public binary package yet;
- alpha formats and APIs may change;
- PCP3 internals retain historical branch-module names;
- Showcase physics remains a bounded proof layer.
