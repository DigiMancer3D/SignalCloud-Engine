# SignalCloud Public Release License Decision

The public SignalCloud Engine source is released under the **MIT License** unless an individual file declares another license. Original starter assets whose provenance declares `CC0-1.0` remain under CC0 1.0. Community packs preserve per-asset licensing and do not receive a blanket license merely by being converted.

Machine-local data, private absolute paths, generated profiles, reports, caches, and conversation records are excluded. The portable core builder creates repository-owned MIT-licensed defaults and records no private machine identity.
