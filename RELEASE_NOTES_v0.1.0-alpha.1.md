# SignalCloud Engine v0.1.0-alpha.1

This public source alpha includes the C++20 point-cloud runtime, ALMOND SIGNAL: LIVE TAPE proof, seven-tool Studio, native SCFONT/SCUI, lighting, materials, Playbooks, Tupd authoring, showcase, stress testing, and public release tooling.

## Portable-core correction

The repaired public source now includes a deterministic privacy-safe core builder. `content/core` is generated locally from repository-owned defaults rather than copied from a developer machine. Run `./scripts/build_core.sh` before setup, or use the patched setup script, which performs the check automatically.
