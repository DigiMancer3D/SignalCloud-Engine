# SignalCloud starter-pack licensing

The starter directory can contain material under more than one license. The
license declared by each asset's provenance or source record is authoritative.

## Original public starter data marked CC0-1.0

Original SignalCloud starter assets and recipes whose metadata explicitly
contains `license_id: CC0-1.0` are dedicated under the Creative Commons CC0 1.0
Universal Public Domain Dedication.

Full legal text: `../../LICENSES/CC0-1.0.txt`

This may include explicitly marked point-cloud starter assets, procedural source
records, physics/visualization profiles, Tupd starter recipes, and supporting
starter metadata.

## Not automatically covered by CC0

CC0 does not automatically apply to:

- engine or tool source code;
- files that declare MIT or another license;
- third-party or user-imported content;
- fonts, textures, models, sounds, or images with separate rights;
- project names, logos, or other branding;
- material with missing or unclear redistribution rights.

Repository code and unmarked project-authored material use the root `LICENSE`
unless a file says otherwise. Third-party material retains its applicable
license and attribution requirements.

Reuse of a starter asset does not imply endorsement by DigiMancer3D or the
SignalCloud Engine project.
